# Workmate AI

Build AI Workplace Productivity Assistant, a modern, responsive SaaS web app using a professional blue and black theme, clean dashboard, sidebar navigation, cards, and mobile-friendly layouts.

Features:

1. Smart Email Generator: Generate personalized, professional emails from user instructions. Include Formal, Friendly, and Persuasive tones. Allow editing and copying outputs.
2. AI Research Assistant: Summarize user-provided articles or topics, identify key insights, and provide actionable recommendations.
3. AI Chatbot: Interactive workplace assistant that answers user prompts with relevant, context-aware AI-generated responses.

Requirements:

- Use React and Tailwind CSS.
- Create a polished dashboard with navigation for Email Generator, Research Assistant, and AI Chat.
- Use structured prompts to generate specific, useful, non-generic responses.
- Make all AI outputs editable and copyable.
- Frontend only: No backend, database, authentication, or server setup.
- Use a browser-compatible AI API integration placeholder with a clearly documented configuration point. Never pretend AI responses are real when no AI service is connected. If no API key is configured, display a clear setup message instead of fake responses.
- Add a responsible AI disclaimer explaining that AI outputs may contain errors and should be reviewed.
- Include loading indicators, error handling, and a professional empty state.

Build a functional, visually polished MVP. Prioritize working frontend interactions, reusable components, and minimal dependencies. Do not add unnecessary features or paid services.
